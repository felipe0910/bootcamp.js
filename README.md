# 🚀 Bootcamp JavaScript - DIO

Repositório destinado ao armazenamento de exercícios, desafios e anotações realizados durante o bootcamp de JavaScript na plataforma DIO.

---

## 🛠️ Tecnologias e Ferramentas
* **Linguagem Principal:** JavaScript (ES6+)
* **Versionamento:** Git & GitHub
* **Ambiente:** Visual Studio Code

---

## 📂 Organização do Aprendizado
O conteúdo está dividido conforme o progresso nas aulas:

* **aula js**: Conceitos iniciais e sintaxe básica da linguagem.
* **estrutura de repeticao**: Práticas com laços de repetição (aula 20).
* **lógica**: Exercícios de verificação, como o sistema de par ou ímpar.
